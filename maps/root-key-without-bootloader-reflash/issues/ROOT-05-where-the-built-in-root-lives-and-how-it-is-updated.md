# 根区放在哪、写满怎么回收

Type: grilling
Opened: 2026-09-30
Status: open
Blocked by: ROOT-01

## Question

内置根照样存在（空板子和恢复出厂之后信它），只是不再编在 bootloader 代码里。它放在 flash 的哪个位置、占多大，用户用 IAPTool 更新它时走什么门禁，才能做到除了存储位置和更新方式之外安全机制一律不变；而且用户连续换根无论多少次（内置根和 owner 根都算），都不改、不重写 bootloader。

**2026-09-30 [决策 72](../../../docs/tables/DECISIONS.md) 之后**：出厂不写任何根，公开根和内置根都取消。本票剩下的是：根区（owner 链 + 撤销）放哪、写满怎么回收；「更新内置根」的门禁不用再定。

**用户 2026-09-30 已定方案 5**：根区并进扇区 15（`0x081E2000` 起 8 KiB），回收时暂存备份 SRAM。下个会话照约定写 `## Answer` 关票。

## 怎么算答完

定下存放位置（地址和空间从哪来）和更新门禁，每个候选方案都画出 flash 分布图；写出它和「编在代码里」相比每一条安全性质是否不变，以及记录区写满时怎么回收、回收时掉电会怎样。
