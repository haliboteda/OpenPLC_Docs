### 查的时候撞出三件事

1. **脚本给了一个假的安心。** 它原本写着第 6 条「由 `host/iapcrypto/` 覆盖」——
   **那个目录不存在**，而真正跑的 `host/bootloader_unit`（H2）只编 bootloader 那份。已改成照实说。
2. **表里第 3 条的 Go 侧只写了「Go 侧解析」，没有文件。** 实际是
   `IAP_Ether.go` 的 `strings.Split(raw, "_")` 和 `IAP_CDC.go`，已补上。
3. **注释已经分叉了，而代码没有。** `discovery_reply_allowed()` 两边**代码一字不差**，
   但解释同一个决定的注释措辞不同 —— core 那份丢了「at 115200 baud」。
   **P2 是绿的，因为它只比数值不比散文。** 这是这整张图要治的病的一个实例。

### 同步的规矩（用户 2026-09-16 定，已写进 ARCHITECTURE）

1. **bootloader 是源。** 先在 `$BOOT` 调试清楚，再同步给其他仓。
2. **改动表里任何一处，当场问用户要不要同步其余位置** —— 不自行决定。
