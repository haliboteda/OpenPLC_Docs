## 新增的工作方式

> 用户 2026-09-16：「**我希望是先文档再代码**（包括实际代码和测试代码）。」

## 每个文件走同一套动作

1. 读它全部叙述性注释
2. 逐段判：**结论**（留）/ **为什么·过程**（搬）
3. 搬走的先和现有文档比对 —— **同一个事实已经写过就不要再写一遍**，只补差额
4. 文档先落盘，跑 P8/P9/P12
5. 再改注释：留结论，加一条指针
6. 记进逐文件台账
