# 报警输出用哪个、正常时是什么状态

Type: grilling
Opened: 2026-09-28
Status: resolved
Blocked by: IEC-02

## Question

标准 2003 5.8 要求固定安装的系统能驱动一个报警输出，正常时处于预定状态。这块板没有专用的报警端子：要不要占一个 DO 或继电器作报警输出、由 core 还是 sketch 驱动、什么情况下报警（看门狗、自检失败），还是在手册里声明不提供。

## 怎么算答完

定下用不用、用哪个输出、何时置位；如果用，真板子上能触发并复位。

## Answer

2026-10-03 定（用户：[决策 80](../../../docs/tables/DECISIONS.md)）。板卡包不提供、也不占用报警输出：用哪一路继电器或 DO、什么时候报，由用户在自己的程序里定义。手册写明标准 2003 5.8 要求固定安装的系统有报警输出、要由用户的程序实现，并建议「正常时吸合、断开即报警」：这样掉电、复位、卡死时输出会自然断开。同日早些时候讨论的「`setup()` 里指定一路由板卡包驱动」作废。

## 引出了什么新的未知

没有。
