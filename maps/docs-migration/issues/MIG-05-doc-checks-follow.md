## Answer

2026-09-16 定。四件：

**一、`$PROD` 改指向本仓，不新造变量。** `$PROD` 这个变量本来就是「产品级文档在哪」，
2026-08-24 它指向 `AI-Skills/OpenPLC` 只是因为当时那里是唯一的去处。
本仓根下就有 `docs/`，所以 `$PROD/docs/...` 这种写法一个字都不用改。
⚠️ **这一步必须和搬文件在同一个 commit 里** —— 提前改，所有现存引用当场指空。

**二、脚本各留各家。** P1–P11 留在 `$TOOL/TestCase/tools/`，它们是 `selfcheck` 的一部分；
本仓自己的两个检查留在本仓，它们查的是本仓的约定。

**三、新增 P12，进 `selfcheck`。** 它调用本仓的两个检查。
这就是 `关票时怎么强制回答` 那张票留下的那条未知的答案：pre-commit 钩子 `--no-verify` 跳得过、
`core.hooksPath` 也不随仓库走，**所以门禁要有一道在 `selfcheck` 里**。

**四、搬迁顺序：加 → 搬 → 减。**

| 步 | 做什么 | 为什么这个顺序 |
|---|---|---|
| **加** | P9 的扫描根加上本仓；`machine.py` 加 `DOCS_REPO` | 纯增量，现状不受影响 |
| **搬** | 移动文件 + `$PROD` 改指向 + 批量改引用，**一个 commit** | 上一次重组弄断 105 处链接、全靠手工找。这次搬完立刻能跑 P9 |
| **减** | 去掉空掉的扫描根 | 最后做，早了会漏扫 |
