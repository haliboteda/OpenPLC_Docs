# 「没有去处」怎么报错

Type: grilling
Opened: 2026-09-16
Status: open
Blocked by: MIG-02

## Question

产出来一个东西、却发现表里没有对应的类别时，现在的做法是在表里写 ⬜「没有去处」然后继续
—— `$PROD/docs/ID-MAP.md` 里三张验收单就是这么待着的，需求 F2 因此一直 🟡。

要定：这种情况怎么变成一个**会报错的信号**，而不是一行安静的 ⬜。

## 怎么算答完

拿 `CHK-*` 那个现成的样本试：按新机制走一遍，它要么得到一个真去处，要么触发一个明确的报错。
「安静地留在表里」不算过。
