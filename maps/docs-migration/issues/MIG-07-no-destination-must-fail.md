# 「没有去处」怎么报错

Type: grilling
Opened: 2026-09-16
Status: resolved
Blocked by: MIG-02

## Question

产出来一个东西、却发现表里没有对应的类别时，现在的做法是在表里写 ⬜「没有去处」然后继续
—— `$PROD/docs/tables/ID-MAP.md` 里三张验收单就是这么待着的，需求 F2 因此一直 🟡。

要定：这种情况怎么变成一个**会报错的信号**，而不是一行安静的 ⬜。

## 怎么算答完

拿 `CHK-*` 那个现成的样本试：按新机制走一遍，它要么得到一个真去处，要么触发一个明确的报错。
「安静地留在表里」不算过。

## Answer

2026-09-16 定。两件事：

**一、`WHERE-THINGS-LIVE.md` 补第六问。** 原来的五问漏了一整类：**跑出来的数据**
（测试结果、逐板记录）。它的去处不是文档，是某个工具的输出位置 ——
`CHK-*` 的 ⬜ 和 `STATUS.md` 的「最近结果」是同一个病：**去处是一个还不存在的工具，
于是被写成占位符然后忘掉。**

**二、占位符不许没人认领。**

> 写下「没有去处」「⬜」「TBD」的同一行，必须指出一张票。

由 [../../../tools/check_no_orphan_placeholders.py](../../../tools/check_no_orphan_placeholders.py) 查，
挂在 [pre-commit](../../../.githooks/pre-commit) 上，**提交过不去**。
它接受额外路径参数，所以能扫还没搬进来的文档。

### 验证

`怎么算答完` 要求「拿 `CHK-*` 那个现成的样本试 —— 要么得到真去处，要么触发明确报错，
安静地留在表里不算过」。拿真文件跑（没有改动它）：

```
$ python tools/check_no_orphan_placeholders.py .../OpenPLC/docs/ID-MAP.md
Orphan placeholders: 1 in 4 document(s).
  .../ID-MAP.md:25: placeholder with no ticket beside it
      | `CHK-A1`-`A7` ... | 大部分是"跑某条命令"或人工 | ⬜ *
exit=1
```

**抓住了，退出码 1。** 本仓自查 0 处，退出码 0。

⚠️ **第一次真提交时它拦住了我自己，而且是误报** —— 它把**定义这条规矩的那份文档**
当成了违规实例（`WHERE-THINGS-LIVE.md` 里引用 ⬜ 作为例子的三行散文）。
已修：**只查表格行**。声明「去处」这件事只发生在单元格里，
散文里引用一个标记不等于缺去处 —— 真样本 `ID-MAP.md:25` 正是一行表格。
修完两边重验：真样本仍然抓得住，本仓 0 处。

⚠️ **这条检查会在搬迁时拦住 `ID-MAP.md`** —— 那是它该有的行为：
搬那一刻必须给 `CHK-*` 一个真去处或一张票，不能把 ⬜ 一起搬进来。
