# 校准除了残差，要不要再拦 k、b 本身

Type: grilling
Opened: 2026-10-09
Status: resolved
Blocked by: -

## Question

拟合只判残差 ≤ 1 % FS（决策 90）。直线拟合会把增益误差吸收进 k：分压电阻焊错、增益偏了 30 % 的板，只要线性好，残差照样过。研发测试里保存校准值之前（决策 97），要不要另加一道「k 偏离 1、b 偏离 0 不超过多少」？

## 怎么算答完

定下要不要拦；要拦的话，四路各自的 k、b 范围。

## Answer

2026-10-10 用户定（[决策 99](../../../docs/tables/DECISIONS.md)）：不拦。校准只取最贴合测得值的 k、b，残差和 k、b 本身都不判；面板显示回归和最终的 k、b。
