# 面板怎么选测试类型、测试项和时长

Type: prototype
Opened: 2026-10-09
Status: resolved
Blocked by: -

## Question

研发测试、第 2–6 步、工装完整测试、制作标准机在面板上怎么摆、怎么选、怎么启动？

## 怎么算答完

用户点过原型，定下布局。

## Answer

2026-10-10 定（用户看过三版原型）：

| 位置 | 放什么 |
|---|---|
| 左上 | 连接：控制口（下面每秒显示板子时间）、板子 USB、网口、RS232 / RS485 / CAN 转换器、标准机、ST-Link、专业设备（预留） |
| 左中 | 测试类型 1–6 |
| 左下 | 工装完整测试、制作标准机 |
| 中 | 端口列表，单选 |
| 右 | 选中端口的测试项卡片：测什么、参数、判据、测得的数值；顶上是时长和「开始」 |
| 最右 | 日志，整页一份，能清空，异常的行变色 |

> ⚠️ **2026-10-13 被[决策 112](../../../docs/tables/DECISIONS.md)改了**：测试类型和两个入口挪到「端口」列上面，左栏只剩连接、可拖宽。

测试类型和两个入口按钮互斥，都只是菜单，点右上角「开始」才启动；各入口的含义见 [决策 97](../../../docs/tables/DECISIONS.md)。原型（已删，现以面板为准）里功能、老化、用户级各存一套参数。
