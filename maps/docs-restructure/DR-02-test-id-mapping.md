## 三个旧编号没有新编号

**不是漏了，是它们没有对应的测试表行。**

| 旧编号 | 是什么 | 为什么没有新编号 |
|---|---|---|
| `M3` | 两块板子的 MAC 不同 | ⛔ 手上只有一块板，**这条用例跑不了**，所以模块测试表里没有它。它证明的 `R1-14` 目前只有静态检查 `P2` 撑着 —— 见 `waiting/WAITING-ON.md` 的「第二块板」 |
| `EV1` | （原定的事件用例） | ⛔ 难以构造，从来没有实现过，模块测试表里没有它 |
| `H3` | `go vet` 扫整个 module | 它是静态检查性质，归工程约束层，**那一层的编号 `P1`–`P12` 不重排** |
