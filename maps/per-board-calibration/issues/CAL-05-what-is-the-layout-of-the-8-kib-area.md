# 校准值区那 8 KiB 里放什么格式

Type: grilling
Opened: 2026-09-28
Status: resolved
Blocked by: CAL-03, CAL-04

## Question

8 KiB 里的记录格式：魔数、版本、长度、CRC 要不要，按通道怎么排，怎么判「还没写过」和「写坏了」，要不要带板子 UID 和校准日期。这份格式会成为工装和 Arduino core 之间的跨仓镜像项，要定它由谁拥有、用什么检查盯住两边一致。

## 怎么算答完

一份字节布局表；写明「没写过」「写坏了」「版本不认识」时 app 各怎么做；写明由 `P2` 还是另一道检查盯两边一致。

## Answer

2026-09-28 定（用户按推荐定）。魔数 + 格式版本 + 板子 UID + 每通道增益和偏移 + CRC32。魔数不对 = 没写过，CRC 不对 = 写坏了，UID 不对 = 不是这块板的；三种情况 app 都退回标称换算并打一行日志。格式由 `$BOOT` 拥有，工装和 core 按它写读，加进 `P2` 盯住两边一致。
