# 用户怎么分清电脑上的一堆串口

Type: grilling
Opened: 2026-10-17
Status: resolved
Blocked by: -

## Question

板子、RS232 / RS485 转接头、USB-CAN 都接在电脑上时，Windows 只显示「USB 串行设备 (COMx)」，Linux 只有 `ttyUSB0` 一类名字，分不出哪个口接哪个端子。

| 用户 2026-10-17 说的 | 内容 |
|---|---|
| 转接头 | 用户自己买或自己做，型号不受我们控制 |
| 谁要分清什么 | Arduino 用户只要在 IDE 端口列表里认出哪个是板子的 USB 口；工装要知道每个转接头接的是板上哪个端子（用户 2026-10-17 更正） |
| 交互 | 工具简单、操作方便；第一次可以麻烦点、由用户指定，以后按指定的别名显示，别名可改 |
| 工装这边 | 暗号自动对号，收不到的再手选（[决策 146](../../../docs/tables/DECISIONS.md)，工装 TODO #86）；手选时可拔插识别 |
| Arduino 这边 | IDE 端口列表里不能出现「同一个口、两个名字」两条；只需认出板子的口，做法在讨论 |

本机一次查到的口（`Get-PnpDevice -Class Ports`）：FTDI `0403:6001`、PL2303GT `067B:23A3` 有序列号；CH340 `1A86:7523` 没有，只有 USB 插口位置；板子 `0483:5740` 序列号每块不同；另有 ST-Link 虚拟串口、蓝牙和虚拟串口软件共十余个干扰项。

## 怎么算答完

交互顺序、别名按什么认（序列号 / 插口位置）、存在哪、工具放哪定下来；先写进文档再写工具。

## Answer

2026-10-17 定：

| 哪边 | 定了什么 |
|---|---|
| 工装 | 暗号自动对上转接头和板上端子，对不上再手选（[决策 146](../../../docs/tables/DECISIONS.md)，工装 TODO #86） |
| Arduino | 只认出板子的 USB 口：`boards.txt` 声明板子的 USB ID，IDE 端口列表里标出板子名；电脑打开 COM 口时心跳灯快闪约 2 s，分清几块板（[M3](../../../docs/modules/M3-app-runtime.md) `R3-25`） |

## 引出了什么新的未知

- `0483:5740` 是 ST 通用 ID，别家 STM32 CDC 设备也会被标成板子名；换成专属 PID（向 ST 申请或 pid.codes）以后只改 `boards.txt` 那两行。ST 对量产产品使用其 VID 的要求未核实
