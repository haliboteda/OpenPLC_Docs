# 一张图怎么算「全做完」

Type: grilling
Opened: 2026-09-16
Status: open
Blocked by: -

## Question

每张票有 `## 怎么算答完`，**整张图没有对应的东西**。

上一张图的终点写窄了（「三个代码仓」，实际七个），而判据是照着终点写的，
于是判据绿了、活没干完。**判据验不了写它的那个范围。**

要定：一张图的 `## Destination` 要不要也带一条能判真假的完整性判据、
谁来验、什么时候验（开图时？关最后一张票时？）。

⚠️ 不要把它做成「再加一张清单」—— 那张清单同样会写窄。要找的是
**从别处独立得出的全集**，而不是从同一个人的印象里再抄一遍。

## 怎么算答完

拿上一张图重放一遍：如果当时有这个机制，「七个仓」和「源码注释里的路径」
这两批**必须**被它捞出来。捞不出来的方案不算数。
