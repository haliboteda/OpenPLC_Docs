# 工装软件真板子演示：操作单

**这份是上板那天照着做的单子。** 只有一块板、没有标准机时，人代替标准机（[决策 108](../tables/DECISIONS.md)）。
每一步写了点哪里、看到什么算对、不对时退回模拟板演示哪一段。引号里是面板原话（`$PORTTOOL/src/ptpanel/web/strings.json` 的中文）；限值出自面板默认的判据方案 `$PORTTOOL/src/plans/station6-poweron.json`，括号里是步骤 id。

> ✅ **分三层，第一层是底线。** 第二层要 AI 跳线焊好、有信号源和万用表；第三层要第二块板当标准机，现在没有，只能在模拟板上演示。哪一步在真板子上出问题，那一步就切到模拟板演示。

| 2 | SDRAM 内存 · 总线检查、全片扫描 | 无 | 「通过」：容量 64 MiB、数据线和地址线都对（`sdram-buses`）；4 种图样 0 处不一致（`sdram-stress`） | 「不过」，❌ 写出哪条总线或几处不一致 | 第 27 条 |
