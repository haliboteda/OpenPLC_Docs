# IEC 61131-2 对这块板意味着什么

2026-09-28 调研得出。**原文引用来自 2003 版全文**（第三方镜像上的授权副本，正式引用前要拿正版核对）；2017 版只核对了范围和目录，正文在付费墙后。

## 1 · 出厂要不要预装 app

> **不要求。** 标准假定应用程序由用户在调试阶段下载进去；它要求的是**没有程序在跑、上电、掉电时输出处于厂商写明的确定状态**。

| 条款 | 要求 | 出处 |
|---|---|---|
| 2017 第 1 节 | 范围是功能和 EMC 要求及验证试验、使用条件、厂商必须提供的信息；目录里没有「出厂程序」条目 | [2017 预览](https://www.plcopen.org/download_file/force/436f0eca-b52f-4bdd-826d-6ae4aa964ef2/342/) |
| 2003 1.1 | 「PLCs, their application programme and their associated peripherals are considered as components of a control system」 | [NEMA IA 2.2-2005 预览](https://www.nema.org/docs/default-source/standards-document-library/ia2-2.pdf?sfvrsn=b6292e24_2) |
| 61131-1:2003 4.6.4 | 应用程序要「down-load or memory cartridge insertion … before start-up」 | [61131-1:2003](https://d1.amobbs.com/bbs_upload782111/files_31/ourdev_569647.pdf) |
| 2003 2.4 / 2.5（2017 4.2.8） | 型式试验时**厂商提供测试程序（PFVP）**，跑遍所有 I/O，验证启动、停机、冷 / 暖 / 热重启。是试验用的，不随产品出厂 | [EN 61131-2:2003](https://www.iec-equipment.com/Uploads/download/EN-61131-2-2003.pdf) |
| 2003 6.3.1.3 | 突然断电到停机之间「no erratic or unintended condition of any kind」 | 同上 |
| 2003 6.3.1.4 | 上电后「start again according to the specifications of the manufacturer … During the start-up, there shall be no erratic or unintended condition」 | 同上 |
| 2003 6.3.2 | 欠压 / 长时间中断：维持正常运行，或进入预定状态并有明确规定的行为 | 同上 |
| 2003 5.8（2017 6.10） | 要有监视用户程序的手段（看门狗）、存储器完整性、电源、MPU 状态的监视；固定安装的要有报警输出，正常时处于预定状态 | 同上 |
| 2003 7.8、7.11.3 | 厂商要写明数字输出在 MPU 失控、欠压、上电 / 掉电时的行为，模拟输出上电 / 掉电时的响应 | 同上 |

## 2 · 模拟量精度

> **标准不规定精度数值。** 它规定误差项怎么声明、单位是什么，偏出厂商声明的限值算型式试验不通过。

| 条款 | 内容 | 出处 |
|---|---|---|
| 2003 5.3.1 表 10 | 输入范围和阻抗：0–10 V 要 ≥10 kΩ；0/4–20 mA 要 ≤300 Ω（0–20 mA 标「Not recommended for future designs」）。没有精度列 | [EN 61131-2:2003](https://www.iec-equipment.com/Uploads/download/EN-61131-2-2003.pdf) |
| 2003 5.3.2 表 11 | 输出负载：电流输出 ≤600 Ω，要承受直至开路的过载 | 同上 |
| 2003 7.10.1 / 7.11.1 | 厂商必须声明：25 °C 最大误差（± % FS）、温度系数（± % FS/K）、全温范围最大误差（± % FS）、分辨率 | 同上 |
| 2003 7.10.2–7.10.4 | 还要声明：EMC 试验中的最大临时偏差、非线性、重复性、单调无失码、通道串扰、保持精度所需的校准周期 | 同上 |
| 2003 2.5、表 29 | 合格判据：模拟量不得偏出厂商声明的限值 | 同上 |
| 2017 6.5.2 / 6.5.3、8.3.9 / 8.3.10 | 对应条款在 2017 版的位置；正文没核实 | [2017 预览](https://www.plcopen.org/download_file/force/436f0eca-b52f-4bdd-826d-6ae4aa964ef2/342/) |
